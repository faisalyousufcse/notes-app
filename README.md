# notes-app

Markdown notes with full-text search and tags.

> Status: planned. This repository holds the project outline, and the code is on its way.

## Overview

A fast, local-first notes app for writing in Markdown and finding things again through tags and search.

## Planned features

- Markdown editor with live preview
- Full-text search across all notes
- Tags, pinning and archives
- Import and export as plain Markdown files

## Tech stack

TypeScript, React, SQLite
